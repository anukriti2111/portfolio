Machine Temperature Anomaly Detection

June 2025
  • Built an unsupervised anomaly detection system on 22,695 time-series machine-temperature readings from the Numenta Anomaly Benchmark (NAB).
  • Compared Dense, LSTM, and Conv1D autoencoders in PyTorch — the Conv1D model came out ahead at 0.000065 test MSE.
  • Flagged machine shutdown and failure events with a 95th-percentile reconstruction-error threshold, an approach that carries directly into predictive maintenance.
